# Assignemnt 1: Pong

The purpose of this assignment is to get you started with pygame and also to get your feet wet with the basics of game development.

This repository contains the final version of the pong game that we did in the class. You are required to make changes to the code to enhance the game of Pong.

## Requirements _[20 marks]_:

- *[5 marks]* Change the color of the ball to green.
- *[5 marks]* Change the shape of the ball to circle.
- *[10 marks]* Implement AI to the right paddle. The paddle should move up if the ball is above it and move down if the ball is below it. Try not to make the paddle AI too hard. The AI paddle should "miss" the ball sometimes.

## Submission:
1. Clone this repository.
1. Make the changes to the code as required.
    - Add any new files to the staging area that you may have created.
1. Commit your changes.
1. Push the changes to the "main branch" of the repository.
